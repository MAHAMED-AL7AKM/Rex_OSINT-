# 🦖 Rex OSINT

> Professional OSINT tool for email, phone, and username reconnaissance.

![Python](https://img.shields.io/badge/Python-3.8+-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Version](https://img.shields.io/badge/Version-1.0.0-red)

## ✨ Features

- 📧 **Email Scanner** – Validates format, runs Holehe, generates dorks
- 📱 **Phone Scanner** – Country, carrier, timezone, direct lookup links
- 👤 **Username Scanner** – Checks 17+ platforms
- 🔍 **Google Dorks Generator** – 5 categories
- 💾 **Auto-save results** in JSON
